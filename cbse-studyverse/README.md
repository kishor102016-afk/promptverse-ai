# CBSE StudyVerse

A responsive, student-friendly study website for CBSE learners in Classes 1–12. Built with plain HTML, CSS, and JavaScript.

## Included
- Class selector for Classes 1–12
- Subject navigation adapted to the selected class
- Search and subject filters
- Sample original lesson summaries and revision notes
- Short multiple-choice chapter quizzes with feedback
- Print / Save as PDF using the browser's print dialog
- Responsive mobile and desktop layout

## Important content coverage note
This is a starter demonstration library, not a complete or officially endorsed CBSE/NCERT syllabus. It contains selected sample lessons. Lesson names and content must be checked against the current prescribed NCERT books and CBSE curriculum for each class and academic year before relying on it for full coverage. CBSE StudyVerse is an independent project and is not affiliated with CBSE or NCERT.

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

## Publish in the existing GitHub Pages repository
These files live in the `cbse-studyverse/` subfolder to keep the root PromptVerse AI site unchanged. If GitHub Pages is already enabled for the repository, the expected site URL is:

`https://kishor102016-afk.github.io/promptverse-ai/cbse-studyverse/`

If it does not load, confirm Pages is deployed from branch `main` and folder `/(root)`, then wait for the latest commit to deploy.

## Save notes as PDF
Open a lesson, choose **Save / print PDF**, then select **Save as PDF** in the browser's print dialog.


## Official Chapter Finder

Open `textbooks.html` from the published StudyVerse site to browse Classes 1–12 subject links to official NCERT textbook selections, ePathshala learning resources, the CBSE 2026–27 curriculum, and official Class X/XII sample papers. The page links to official resources instead of copying or rehosting copyrighted textbook chapters. Subject availability and chapter coverage should be verified against each school's prescribed books.
