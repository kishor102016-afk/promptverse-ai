# PromptVerse AI

A responsive, dark-themed AI prompt-sharing gallery built with HTML, CSS, and vanilla JavaScript.

## Features
- Search prompts by title, category, tags, and prompt text
- Filter by AI images, stories, gaming, sports, and technology
- Sort prompts alphabetically
- Copy prompt text and save favorites for the current page session
- Add prompts to the in-browser demo list

## Run locally
Open `index.html` in a modern browser.

## Important demo note
This is a static front-end demo. Prompts added through the form are not stored permanently or shared with other visitors. A real community submission system would need a backend and persistent database.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait a few minutes for the deployment, then open the published site.
